Your privacy and choices

What stays in your browser, and what reaches another service.

Private collections

Favorites, folders and notes stay in this browser. Clearing browser data can remove them. A private JSON backup contains notes and folder names; keep it private. Import reads it locally. Sharing requires review and exposes up to 50 selected tool IDs in a link fragment. Notes and folder names are excluded. Ordinary search links include search text and filters; review them before sending.

Clicks and optional measurements

Destination clicks are aggregate link opens, not unique people. Events contain a catalog ID and a random event ID, with a browser cooldown and bounded server limits. Historical totals can include controlled verification events. Test/offline mode sends no events.

Additional discovery measurements are off by default. If enabled, they contain fixed buckets only: results or zero results, a broad time-to-open interval, and yes/no task feedback. Raw queries, notes, folder names, account IDs and persistent visitor IDs are excluded from these events. Aggregate totals are owner-only. Random measurement IDs expire after 24 hours; aggregate retention is 90 days. Network providers may retain routine logs.

Third-party tools

External tools have their own terms. Local-processing labels apply only to documented core tasks. Cloud tools receive files. Mixed or unknown processing requires checking the feature. Public security scanners can share submissions; never submit confidential material.

The Commons

Accounts require email verification and owner approval before posting. Published posts and shared profiles are public. Reports and account settings have separate permissions. Edward is an automated moderator with bounded catalog-based replies, without access to private ChatGPT chats or inboxes. Request account deletion through My account; a request is not completed deletion.
